✨ What is Farder?

💬 About Farder

Farder combines the best of Discord (servers, channels, roles), TeamSpeak (self-hosted), Signal (end-to-end encryption), and IRC (lightweight, user-controlled) into a platform you actually own. There is no Farder Inc. watching your messages. There is no central server. There is just software.

🔑
Cryptographic Identity
Your identity is an Ed25519 keypair. No email, no phone number, no account — just a key.
🛡️
End-to-End Encrypted DMs
Direct messages use X25519 key exchange + AES-256-GCM. The server cannot read them.
🌐
IP Privacy via Relay
All traffic routes through privacy relay nodes. Your IP is never exposed to servers or other users.
🏠
Self-Hosted
Run your own Farder server. Full control. No dependency on any central authority.
📂
Channels & Roles
Organize communities with text channels, categories, roles, and permissions — just like you'd expect.
🖥️
Retro XP Aesthetic
Tahoma font. Luna Blue. Raised buttons. Because computing was more honest then.

🔗 How Invite Links Work

Farder invite links encode both the server address and a one-time code. When a server admin generates an invite, they share a link like:

Example invite URL
farder.gg/join/cGxheS5mYXJkZXIuZ2c6NDQzNS9BYkMxMjN4WQ
1 The server admin opens the invite dialog in Farder and creates an invite link.
2 They share the link, which looks like farder.gg/join/ENCODED_TOKEN — a compact URL where the token is a base64-encoded combination of the server address and invite code.
3 You click the link. This page opens and offers to launch Farder directly via the farder:// protocol handler.
4 If Farder is installed, it opens and connects you to the server automatically. If not, download it above.
Invite codes are server-specific and single-use. They expire once redeemed or after a configurable time limit set by the server admin.
