# Incoming Webhooks (v1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** External services POST a Discord-compatible body to a relay URL and it appears as a WEBHOOK-tagged message in a Farder channel, without exposing the server's IP.

**Architecture:** The relay grows a minimal axum HTTP endpoint (`POST /webhook/{server_id}/{token}`) that looks the registered server up by `server_id` and forwards `{token, body}` over the existing QUIC tunnel via a new `RelayStreamRole::Webhook`. The server validates the token against a `webhooks` table, parses `{content, username?}`, and posts a message authored by the webhook's generated key with an `author_name_override`.

**Tech Stack:** Rust (`farder-relay`, `farder-server`, `farder-protocol`), quinn/QUIC, axum (new relay dep), rusqlite, Tauri, React/TS.

## Global Constraints

- **Verify-before-done:** shipping this needs a **relay redeploy** (VPS) + server sidecar rebuild; the relay HTTP path is deploy-gated. Mark UNVERIFIED until the owner's runtime test.
- **Privacy:** the relay never stores webhook tokens — it routes by the non-secret `server_id` and forwards; the **server validates the token**. The server's IP is never exposed.
- **Protocol rollout order:** adding a `RelayStreamRole::Webhook` variant is MessagePack-index-tagged, so an old server can't decode it. **Deploy the server (Task 1) before the relay starts emitting it (Task 2)** — this plan sequences server-first.
- **Discord compatibility:** accept `{"content": <non-empty string>, "username": <optional string>}`; ignore unknown fields (`embeds`, `avatar_url`) without erroring; reject missing/empty `content`.
- **Limits:** relay: per-IP rate limit (reuse `ConnectionLimiter`) + body-size cap (64 KiB) before forwarding. Server: per-webhook rate limit + reuse the message content-length cap.
- **Framing:** relay↔server streams use a 4-byte big-endian length prefix + MessagePack (`codec::encode`/`decode`); the relay stamps handle `0` (relay-originated) before the role frame.
- **Seam rule:** new Tauri commands registered in `generate_handler!` with matching invoke names. **Casing:** TS server types snake_case; invoke args camelCase.
- **UI styling:** any new className added to all three `client/src/themes/*/theme.css`.
- **Build/test:** `cargo test -p farder-server`; `cargo build --workspace` (a new `RelayStreamRole`/`ServerRequest`/`MessageInfo` field breaks exhaustive matches / struct literals across the workspace); `cd client && npx tsc --noEmit`.

```rust
use anyhow::{bail, Result};
use rusqlite::{params, Connection, OptionalExtension};
use farder_crypto::identity::{Keypair, PublicKey};

pub struct WebhookRow { pub id: i64, pub channel_id: u64, pub name: String, pub public_key: PublicKey }
pub struct WebhookPayload { pub content: String, pub username: Option<String> }

pub fn parse_webhook_payload(body: &[u8]) -> Result<WebhookPayload> {
    let v: serde_json::Value = serde_json::from_slice(body).map_err(|_| anyhow::anyhow!("invalid json"))?;
    let content = v.get("content").and_then(|c| c.as_str()).unwrap_or("").trim().to_string();
    if content.is_empty() { bail!("missing content"); }
    let username = v.get("username").and_then(|u| u.as_str()).map(|s| s.trim().to_string()).filter(|s| !s.is_empty());
    Ok(WebhookPayload { content, username })
}

fn gen_token() -> String { hex::encode(Keypair::generate().public_key().as_bytes()) } // 64-hex high-entropy secret

pub fn create(conn: &Connection, channel_id: u64, name: &str) -> Result<(i64, String)> {
    let token = gen_token();
    let pk = Keypair::generate().public_key();
    conn.execute("INSERT INTO webhooks (channel_id, token, name, public_key, created_at) VALUES (?1,?2,?3,?4,?5)",
        params![channel_id as i64, token, name, pk.as_bytes().as_slice(), crate::db::now() as i64])?;
    Ok((conn.last_insert_rowid(), token))
}
pub fn regenerate_token(conn: &Connection, id: i64) -> Result<Option<String>> {
    let token = gen_token();
    let n = conn.execute("UPDATE webhooks SET token = ?1 WHERE id = ?2", params![token, id])?;
    Ok((n > 0).then_some(token))
}
pub fn delete(conn: &Connection, id: i64) -> Result<()> { conn.execute("DELETE FROM webhooks WHERE id=?1", params![id])?; Ok(()) }
pub fn list_for_channel(conn: &Connection, channel_id: u64) -> Result<Vec<WebhookRow>> {
    let mut stmt = conn.prepare("SELECT id, channel_id, name, public_key FROM webhooks WHERE channel_id = ?1")?;
    let rows = stmt.query_map(params![channel_id as i64], row_to_webhook)?;
    let mut out = Vec::new(); for r in rows { out.push(r?); } Ok(out)
}
pub fn find_by_token(conn: &Connection, token: &str) -> Result<Option<WebhookRow>> {
    conn.query_row("SELECT id, channel_id, name, public_key FROM webhooks WHERE token = ?1", params![token], row_to_webhook).optional().map_err(Into::into)
}
fn row_to_webhook(r: &rusqlite::Row) -> rusqlite::Result<WebhookRow> {
    let pk_b: Vec<u8> = r.get(3)?;
    let arr: [u8;32] = pk_b.try_into().map_err(|_| rusqlite::Error::InvalidQuery)?;
    Ok(WebhookRow { id: r.get(0)?, channel_id: r.get::<_,i64>(1)? as u64, name: r.get(2)?, public_key: PublicKey::from_bytes(arr) })
}

#[derive(Debug, PartialEq)]
pub enum WebhookAck { Ok, Unauthorized, BadRequest, TooLarge }

/// Validate + post. `body` is the raw HTTP body. Async (broadcast).
pub async fn deliver(state: &std::sync::Arc<crate::state::ServerState>, token: &str, body: &[u8]) -> WebhookAck {
    if body.len() > 64 * 1024 { return WebhookAck::TooLarge; }
    let (channel_id, author, name, message) = {
        let conn = state.db.lock().unwrap();
        let Some(wh) = find_by_token(&conn, token).ok().flatten() else { return WebhookAck::Unauthorized; };
        let payload = match parse_webhook_payload(body) { Ok(p) => p, Err(_) => return WebhookAck::BadRequest };
        let content: String = payload.content.chars().take(8000).collect();
        let display = payload.username.unwrap_or_else(|| wh.name.clone());
        let mid = match crate::messages::insert_message_with_author_name(&conn, wh.channel_id, &wh.public_key, &content, None, Some(&display)) {
            Ok(m) => m, Err(_) => return WebhookAck::BadRequest };
        let message = match crate::messages::get_message(&conn, mid, &wh.public_key) { Ok(Some(m)) => m, _ => return WebhookAck::BadRequest };
        (wh.channel_id, wh.public_key, display, message)
    };
    let _ = (author, name);
    crate::connection::broadcast_event(state, crate::events::EventTarget::Subscribers(channel_id),
        farder_protocol::server::ServerEvent::NewMessage { message }).await;
    WebhookAck::Ok
}
```

```rust
use axum::{extract::{Path, State, ConnectInfo}, http::StatusCode, routing::post, Router};
use std::{net::SocketAddr, sync::Arc};
use crate::router::SharedState;
use farder_protocol::{codec, server::RelayStreamRole};

pub async fn serve(bind: SocketAddr, state: SharedState, limiter: Arc<crate::limits::ConnectionLimiter>) -> anyhow::Result<()> {
    let app = Router::new()
        .route("/webhook/:server_id/:token", post(handle))
        .with_state((state, limiter));
    let listener = tokio::net::TcpListener::bind(bind).await?;
    tracing::info!("webhook HTTP listening on {}", bind);
    axum::serve(listener, app.into_make_service_with_connect_info::<SocketAddr>()).await?;
    Ok(())
}

async fn handle(
    State((state, limiter)): State<(SharedState, Arc<crate::limits::ConnectionLimiter>)>,
    Path((server_id, token)): Path<(String, String)>,
    ConnectInfo(peer): ConnectInfo<SocketAddr>,
    body: axum::body::Bytes,
) -> StatusCode {
    if limiter.try_admit(peer.ip(), std::time::Instant::now()).is_none() { return StatusCode::TOO_MANY_REQUESTS; }
    if body.len() > 64 * 1024 { return StatusCode::PAYLOAD_TOO_LARGE; }
    let Ok(id_bytes) = hex::decode(&server_id) else { return StatusCode::NOT_FOUND };
    let conn = { let map = state.servers.read().await; map.get(&id_bytes).map(|r| r.conn.clone()) };
    let Some(conn) = conn else { return StatusCode::NOT_FOUND };
    match forward(&conn, token, body.to_vec()).await {
        Ok(code) => StatusCode::from_u16(code).unwrap_or(StatusCode::BAD_GATEWAY),
        Err(_) => StatusCode::BAD_GATEWAY,
    }
}

async fn forward(conn: &quinn::Connection, token: String, body: Vec<u8>) -> anyhow::Result<u16> {
    let (mut s, mut r) = conn.open_bi().await?;
    s.write_all(&0u32.to_be_bytes()).await?;                              // reserved handle 0 (relay-originated)
    crate::proxy::write_framed(&mut s, &codec::encode(&RelayStreamRole::Webhook { token, body })?).await?;
    let ack = crate::proxy::read_framed(&mut r).await?;                    // 2-byte big-endian status
    if ack.len() < 2 { anyhow::bail!("short webhook ack"); }
    Ok(u16::from_be_bytes([ack[0], ack[1]]))
}
```
